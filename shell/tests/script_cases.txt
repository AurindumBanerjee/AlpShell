AlpShell script tests. Each case is run with `bash script` and with `alpshell script`; stdout, stderr (after
stripping the "case.sh: line N:" / "alpshell:" prefix) and the exit status must match.

A case starts with a line "=== name". Optional "#! key: value" lines follow:
  compare: stdout status    compare only these (error messages and signal notices differ between shells)
  diff: reason              an intentional difference from bash: the case then checks alpshell's own output
  alp-stdout: text          alpshell's expected stdout for a diff case (Python string escapes)
  alp-status: N             alpshell's expected exit status for a diff case
The rest of the case is the script. Everything before the first "===" is ignored.

=== diff_echo_dash_e
#! diff: the echo builtin only knows -n; bash also has -e and -E
#! alp-stdout: -e a\\tb\n
#! alp-status: 0
echo -e 'a\tb'

=== diff_special_parameters
#! diff: $# $@ $* are not implemented and stay literal; bash expands them
#! alp-stdout: $# $@ $*\n
#! alp-status: 0

=== diff_parameter_operators
#! diff: ${VAR:-default} and the other parameter operators are not supported: bad substitution, status 1 for that command
#! alp-stdout: after\n
#! alp-status: 0

echo after

=== diff_command_substitution
#! diff: $(...) and backticks are not implemented

=== diff_control_flow
#! diff: if, for, while and functions are not implemented, so their keywords are looked up as commands
#! alp-stdout:
#! alp-status: 127

=== diff_here_documents

=== diff_subshell_grouping
#! diff: ( ) subshells and { } groups are not implemented: "(echo" is looked up as a command and the ")" stays in the word
